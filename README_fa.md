# خط لوله هوش مصنوعی برای غربالگری بیماری‌های متابولیک نادر (LC-HR-MS)

خلاصه‌ی فارسی. نسخه‌ی کامل در [README.md](README.md) است.

**چه کار می‌کند؟** از جدول ویژگی‌های طیف‌سنجی جرمی (m/z، زمان نگه‌داری، شدت) شروع می‌کند. متابولیت‌ها را با جرم دقیق (±۵ ppm) و RT شناسایی می‌کند و ایزوبارها، مثل Leu/Ile و allo-Ile، را با RT از هم جدا می‌کند. بعد داده را پاک‌سازی و نرمال‌سازی می‌کند (batch correction و PQN). سپس z-score هر متابولیت را نسبت به جمعیت سالم، نسبت‌های تشخیصی (Phe/Tyr، C3/C2، C8/C10، Cit/Arg و ...) و امتیاز مسیرهای متابولیکی را محاسبه می‌کند. در نهایت با یادگیری ماشین برای ۸ بیماری (PKU، MSUD، تیروزینمی نوع ۱، PA/MMA، MCADD، سیترولینمی، GA1 و IVA) تصمیم «پرخطر/کم‌خطر» می‌گیرد و دلیلش را هم توضیح می‌دهد.

**نتایج اصلی (روی مجموعه‌ی تست جداشده)**
- در حالت دو مرحله‌ای (cut-off کلاسیک و بعد ML)، **مثبت کاذب ۴۰٪ کم شد** (از ۱۰۹ به ۶۵) و PPV از ۰٫۴۱ به ۰٫۵۴ رسید.
- در حالت مستقل، ML موارد از دست رفته را از ۴ به ۳ رساند.
- تشخیص نوع بیماری: ۱۰۰٪ (۸۰ از ۸۰).
- نشان داد چرا TPN و نوزاد نارس، cut-off را گول می‌زنند ولی نسبت‌ها نه. همچنین نشان داد چرا pivaloylcarnitine که با C5 ایزوبار است فقط با MS/MS حل می‌شود.

⚠️ داده‌ها **مصنوعی** ولی بر پایه‌ی بیوشیمی واقعی ساخته شده‌اند. این یک نمونه‌ی پژوهشی است و ابزار پزشکی نیست.

**اجرا**

```bash
pip install -r requirements.txt
python run_pipeline.py

```
